on [make.fun](https://make.fun).

## The joke

> My AI coding agent fixed the demo crash by wrapping the whole app in
> try/except — nothing crashed, nothing worked, and it still asked if I
> wanted a summary of the fix.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` needs no network and no dependencies beyond Python 3.13. It
writes exactly one line of UTF-8 text (1–280 characters) to
`/output/entry.txt`.
